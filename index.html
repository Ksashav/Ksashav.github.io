AWS CI/CD pipeline, rebuilt as Terraform

nextwork-cicd-terraform

I built this pipeline by hand in the console first, over six days. Then I rewrote it as 33 Terraform resources across 13 files, destroyed everything, and rebuilt it from an empty account.

During the rebuild I found four defects the working console version had hidden. In one, a deployment reported seven successful lifecycle hooks and served nothing: systemctl start does nothing to a running service, and the scripts had no set -e.

I wrote the IAM policies before the first apply. The build role took four rounds of AccessDenied in the console and worked first time as code. I keep state in an encrypted, versioned S3 bucket with native use_lockfile locking.

How I tested it I ran a drift experiment. When I changed a tag by hand, plan offered to revert it. When I opened port 443 to the internet by hand, plan showed nothing, because separate rule resources don't make the security group authoritative.
