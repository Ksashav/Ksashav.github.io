GCP / GKE DevSecOps Platform

secops-gke-platform Terraform · Keyless CI/CD · Detection-as-code

Personal project

The GCP twin of my AWS anomaly-detection work: same patterns, second cloud, all of it as code.

  • Cost has guardrails: a £10 monthly budget alerting at 50, 90 and 100%, attribution labels, Spot nodes, and autoscaling that can go to zero.
  • The Kafka side (KRaft, single broker, separate consumer Deployment) cost me an evening on __consumer_offsets refusing to create, because the default replication factor was more than one broker could satisfy.

Anomaly Detection Proxy

network-anomaly-detector Kubernetes · Helm · Python

Personal project

  • A Python reverse proxy reads inbound HTTP live and flags three things: more than ten requests from one IP in sixty seconds (aged by timestamp, so the window actually moves), probes at /admin, /.env and /config, and scanner user-agents like sqlmap, nmap and nikto.
  • It logs and forwards rather than blocking. On a financial platform, a false positive that drops a real customer costs more than a scanner you watched go past.
  • Three replicas on Kubernetes. I checked self-healing the blunt way, by deleting pods and watching the controller put them back, with the app exposed through a NodePort Service.
  • Helm packaging with dev, staging and prod values files, so a deploy is one command and so is a rollback.
  • AWS credentials arrive as Kubernetes Secrets at runtime. Alerts land in S3 as timestamped JSON.
