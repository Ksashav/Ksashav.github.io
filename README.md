# ksashav.github.io

Personal CV site — Oleksandr Kolko, junior cloud / DevOps engineer.

Single static page, no build step and no dependencies: all CSS is inline, all icons are
inline SVG, and the only external request is to Google Fonts.

- `index.html` — the site
- `cv.pdf` — downloadable CV

Deployed with GitHub Pages from the `main` branch.
